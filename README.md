# iot-learning-system

非情報系学生を対象とした、Web教材とゲーム型IoTトイによる
IoT体験学習システムです。

## 研究構想

Web教材でIoTの基本を学習した後、IoTトイに搭載された
センサから取得したデータをWeb上で可視化します。

学習者はWeb上に表示されたセンサデータを利用しながら、
ペアで協力してゲームを進めます。

## 現在の開発範囲

- IoTの基礎を学習するWeb教材
- センサデータの可視化画面
- 協力型ゲームの説明画面
