ABOUT

この教材について

IoTに詳しくない学習者でも、Web上の説明と実物の操作を通して、 IoTの基本的な仕組みを学べる教材を目指しています。

01

Webで学ぶ

IoTの定義や構成要素、身近な活用例を順番に学習します。

02

データを見る

実物のセンサから取得したデータをWeb上で確認します。

03

実物を操作する

可視化された情報を利用しながら、IoTトイを操作します。

LEARNING FLOW

学習の流れ

  1. 1

    IoTについて学ぶ

    センサ、通信、データ処理、可視化、機器制御について学習します。

  2. 2

    センサデータを確認する

    IoTトイから送られたセンサデータをWeb画面に表示します。

  3. 3

    協力してゲームに挑戦する

    PC担当とトイ担当に分かれ、センサデータを利用して課題を解決します。

  4. 4

    IoTの流れを振り返る

    取得した情報がどのように送信・利用されたかを確認します。

GOAL

この教材の学習目標

  • IoTの基本的な仕組みを説明できる
  • センサの役割を説明できる
  • ネットワークを介してデータを確認できることを理解する
  • 可視化したデータを機器の操作に利用できることを理解する

準備ができたら、IoTの基礎学習を始めましょう。
